## Purpose

This vault is intended to act as the source of truth for the automation operating system:

- Obsidian stores project status, context, decisions, and execution logs.
- Codex reads the Markdown files and updates project files after work.
- ChatGPT reviews the current state and helps summarize risks, next actions, and project direction.

## Initial Operating Rule

Project status should live in this vault, not only inside chat history.
